# Testimonials (echte WhatsApp-Screenshots)

Hier kommen die **echten, mit Einwilligung geteilten** WhatsApp-Screenshots rein.

## So fügst du einen hinzu
1. Screenshot **auf die Sprechblase zuschneiden** (WhatsApp-Eingabeleiste + leerer Rand unten weg — nur die Nachricht + Uhrzeit).
2. Als **JPG oder PNG** speichern.
3. Datei hier ablegen (in Lovable: Bild hochladen in `public/images/testimonials/`).
4. Dateiname eintragen in `src/pages/reset/ResetNext.tsx` → Konstante `TESTIMONIALS`.

## Aktuell erwartete Dateien
- `wa-1.jpg` — erste Klientin (Fettabbau + „fokussierter/selbstbestimmter")

Weitere ergänzen: neue Zeile in `TESTIMONIALS` + Datei hochladen.
Ideal: je 1 zu Energie / Schlaf / Struktur (Gefühls-Aussagen, nicht nur Kilos).

Hinweis: Zeigt die Komponente kein Bild, prüfe Dateiname + Pfad — bei fehlendem
Bild blendet sich der ganze Testimonial-Block automatisch aus (kein kaputtes Icon).
